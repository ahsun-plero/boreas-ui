# Claude Agents for Boreas UI

This directory contains agent configurations for building components and layouts in the boreas-ui project. These agents are designed to work with the Claude Agent SDK and can be invoked to automate component and layout creation.

## Available Agents

### 1. Frontend Engineer Agent
**Path:** `.claude/agents/frontend-engineer.md`

Builds responsive, reusable components based on design specifications. The agent:
- Takes component specs (name, props, styles, behavior)
- Creates EJS templates with full Tailwind styling
- Handles mobile, tablet, and desktop responsiveness
- Generates proper component structure for the project
- Outputs ready-to-use components in `src/components/`

**Invoke with:**
```bash
claude-code agent run frontend-engineer --spec "component_name: card, props: [title, description, image], responsive: true"
```

### 2. Layout Builder Agent
**Path:** `.claude/agents/layout-builder.md`

Builds complete page layouts using containers and asks for specifications. The agent:
- Creates layout structure using containers and sections
- Asks for grid/flex configuration per screen size
- Determines column counts for each breakpoint
- Combines components into cohesive layouts
- Generates complete page templates in `src/pages/`

**Invoke with:**
```bash
claude-code agent run layout-builder --layout "homepage" --sections "hero, features, cta, testimonials"
```

## Agent Workflow

### Creating a Component

1. **Specify Component Needs**
   - Component name and purpose
   - Props/inputs needed
   - Visual styling requirements
   - Responsive behavior

2. **Frontend Engineer Agent**
   - Creates EJS template with props
   - Applies Tailwind CSS utilities
   - Adds mobile/tablet/desktop variants
   - Places in `src/components/`

3. **Build & Test**
   ```bash
   npm run build
   npm run preview
   ```

### Building a Layout

1. **Define Layout Structure**
   - Page name and purpose
   - Which sections/containers needed
   - Components to include

2. **Layout Builder Agent**
   - Asks for grid specifications
   - Determines breakpoint columns (sm, md, lg, xl)
   - Asks for flex direction, alignment, spacing
   - Creates complete page template
   - Imports and positions components

3. **Build & Deploy**
   ```bash
   npm run build
   # dist/layout-name.html ready
   ```

## Component Specifications Format

When giving specs to the frontend engineer agent, use this format:

```
Component Name: Hero Section
Purpose: Large banner with headline, subtext, and CTA button

Props:
- title (string): Main headline text
- subtitle (string): Supporting text
- backgroundImage (string): URL to hero background
- ctaText (string): Button text
- ctaHref (string): Button link
- ctaVariant (string): "primary" or "secondary"

Styling:
- Full width with padding
- Large typography (h1 size heading)
- Overlay effect on background image
- Gradient overlay: dark to transparent

Responsive Behavior:
- Mobile: Single column, smaller padding
- Tablet: Centered content, medium padding
- Desktop: Full width with side padding, large padding
- Text sizes: Mobile sm → Tablet base → Desktop lg

States:
- Hover: Button hover effect
- Dark mode: Support dark variant
```

## Layout Specifications Format

When building layouts, provide structure like:

```
Layout Name: Homepage

Sections:
1. Header - Navigation (sticky)
2. Hero - Large hero section
3. Features - Grid of 3 feature cards
4. CTA - Call-to-action section
5. Testimonials - Carousel of testimonials
6. Footer - Navigation and info

Grid Questions (Agent will ask):
- How many columns per section per screen size?
- Which sections should stack vs. flow?
- Spacing between sections?
- Container max-width?
- Padding around content?

Components to Use:
- src/components/header.ejs
- src/components/hero.ejs
- src/components/card.ejs
- src/components/testimonial.ejs
- src/components/footer.ejs
```

## Quick Start

### Create Your First Component

```bash
# Tell the agent what you want
claude-code agent run frontend-engineer \
  --spec "
    name: Feature Card
    props: [icon, title, description]
    styling: white background with shadow, blue text for title
    responsive: yes, full width mobile, 1/3 width desktop
  "
```

### Build a Layout

```bash
# Describe your layout
claude-code agent run layout-builder \
  --layout "about-page" \
  --sections "header, hero, about-content, team-grid, cta, footer"
```

## Integration with Project

- **Components created** → Automatically placed in `src/components/`
- **Layouts created** → Automatically placed in `src/pages/`
- **Styles** → Uses project's `tailwind.config.js`
- **Build** → Run `npm run build` to compile all

## Tips

1. **Component First**: Build components, then compose them into layouts
2. **Reuse Components**: Ask for variants rather than new components
3. **Consistent Specs**: Use the same format for all specs
4. **Test Locally**: Preview `dist/index.html` in browser before deploying
5. **Iterate**: Get feedback and iterate on designs
